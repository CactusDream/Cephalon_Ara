# 🌌 Cephalon Ara (세팔론 아라) - Beta v0.3.5

**세팔론 아라(Cephalon Ara)**는 한국 워프레임 플레이어를 위한 **실시간 정보 및 유틸리티 도구**입니다.
현재 **오픈 베타(Open Beta)** 테스트 중이며, 여러분의 피드백을 바탕으로 성장하고 있습니다.

---

## ✨ 주요 기능

### 1. 성유물 보상 스캔 (`F7`)
- 성유물 까는 화면에서 `F7`을 누르면 화면을 인식해 보상 아이템 4종을 읽어옵니다.
- 각 아이템의 **플래티넘 시세**와 **두캇 가치**를 오버레이로 바로 보여줍니다.
- 게임 로그를 감시해서 보상 선택 화면에 진입하면 **자동으로 스캔**하는 옵션을 지원합니다(설정에서 켜고 끌 수 있음).
- 기본적으로 FHD(1920×1080)/QHD(2560×1440) 해상도에 맞춰진 고정 영역을 스캔하며, 설정의 **"유동적 스캔"**을 켜면 다른 해상도·화면비에도 자동으로 영역을 맞춰 인식합니다.

### 2. 리벤 모드 분석 & 시세 검색 (`F8`)
- 리벤 모드 정보창에서 `F8`을 누르면 해당 리벤을 정밀 분석합니다.
- **등급 판별**: 무기 기질과 옵션 수치를 분석해 **S/A/B/C 등급**과 진행률(%)을 시각적으로 보여줍니다.

### 3. 마켓 검색 탭
- 워프레임 마켓 웹사이트를 켜지 않고도 프로그램 안에서 시세를 조회할 수 있습니다.
- 한글 아이템명으로 검색하면 판매/구매 매물을 바로 보여줍니다.
- 시세 데이터는 자체 캐시 서버를 통해 제공되며, 과도한 호출을 막기 위해 일정 시간 캐싱됩니다(검색 시 약간의 지연이 있을 수 있습니다).

### 4. 파밍 목표 관리
- 모으고 싶은 프라임 부품을 검색해서 "파밍 목표"로 등록할 수 있습니다.
- 등록해 둔 아이템이 `F7` 스캔 결과에 나타나면 오버레이에서 강조 표시되어, 깔지 말아야 할 성유물을 놓치지 않게 도와줍니다.

### 5. 실시간 월드 상태 대시보드
- **오픈월드 사이클**: 시터스(낮/밤), 오브 협곡(따뜻함/추움), 캠비온 퇴적지(Vome/Fass), 두비리 감정 상태를 실시간으로 보여줍니다.
- **숙제/주간 관리**: 신디케이트 임무, 이번 주 집정관 사냥, 중재(Arbitration)·강철의 길 미션, 균열(Fissure) 현황, 바로 키'티어 도착 정보를 한 화면에서 확인할 수 있습니다.
- **알림 설정**: 원하는 보상이 걸린 얼럿·침공이나 특정 중재 미션을 등록해두면 알림을 받을 수 있습니다.

### 6. 자동 업데이트
- 실행 시 GitHub 릴리즈를 확인해 새 버전이 있으면 알려주고, 원하면 곧바로 받아 적용할 수 있습니다.
- 소스에서 직접 실행하는 개발 환경에서는 자동 업데이트 확인이 동작하지 않습니다.

## 🚀 설치 및 사용 방법

1. **실행**: `CephalonAra.exe`를 실행합니다.
2. **최초 설정**
   - 처음 실행하면 `config.ini`가 자동으로 생성됩니다.
   - **Tesseract OCR**이 `bin/tesseract/`에 내장되어 있습니다. 인식이 잘 안 된다면 [Tesseract 공식 사이트](https://github.com/UB-Mannheim/tesseract/wiki)에서 별도로 설치한 뒤 경로를 맞춰주세요.
   - 해상도는 FHD/QHD를 기본 지원하며, 그 외 해상도나 화면비를 쓴다면 설정에서 **유동적 스캔**을 켜는 것을 권장합니다.
3. **게임 디스플레이 모드**
   - **전체화면** 또는 **창모드(테두리 없음, Borderless)**에서 가장 안정적으로 동작합니다.
   - 테두리가 있는 일반 **창 모드**는 해상도·배율에 따라 인식 위치가 어긋날 수 있어 현재 개선 작업 중입니다. 정확한 인식이 필요하다면 위 두 모드를 권장합니다.
4. **사용**
   - 성유물 보상 화면 → `F7` (자동 스캔이 켜져 있으면 자동으로 동작)
   - 리벤 모드 정보창 → `F8`

## 🛠 개발 중인 기능

다음 기능들은 현재 개발 진행 중이며, 이번 v0.3.5에는 포함되어 있지 않습니다.

- 워프레임 마켓 로그인 연동을 통한 매물 등록/구매/관리
- 일반 창 모드(테두리 있는 창)에서의 스캔 정확도 개선
- 두캇/플래티넘 중 어느 쪽으로 파는 게 유리한지 비교해주는 "두카네이터" 기능
